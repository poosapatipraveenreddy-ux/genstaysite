Key Vault — Encrypted API Key & Credential Manager

Key Vault is a Chrome browser extension that opens in the side panel and lets freelancers and developers keep API keys and credentials in an encrypted vault stored on their own device. Keys are organized into Personal and per-client workspaces.

Workflow & Organization

Built for Developer Productivity

Keep sensitive tokens and client credentials neatly organized, protected, and available right beside your work.

🔐

Local Device Encrypted Vault

Your API keys, secrets, and auth tokens are encrypted using standard cryptography and stored strictly on your own device. No external servers or third-party cloud databases ever hold your keys.

📑

Chrome Side Panel Access

Opens seamlessly in Google Chrome’s native side panel. Retrieve, copy, and manage credentials alongside your development dashboard, code editor, or API client without tab switching.

🗂️

Personal & Client Workspaces

Organize keys into dedicated workspaces. Keep your personal keys separate from individual client projects, avoiding accidental key leakage or credential mix-ups.

🔢

Quick 4-Digit PIN Unlock

Unlock your vault throughout the day with a fast 4-digit PIN. The PIN is sealed by an internal hardware device key in IndexedDB with brute-force rate limiting.

🧹

30s Auto Clipboard Clearing

Once you copy an API key, the extension automatically clears the clipboard after 30 seconds via an offscreen service to prevent clipboard snooping.

🔄

Encrypted Profile Sync

Optionally sync your encrypted vault across your Chrome profile. Only ciphertext is synced; your master password and PIN never leave your machine.

Setup in 60 Seconds

How to Install Key Vault

Key Vault is built on Manifest V3 and runs on Chrome 120+, Microsoft Edge, or Brave.

Open Extension Settings

Open chrome://extensions in your browser and toggle on Developer mode in the top right.

Load Unpacked Extension

Click Load unpacked and select the Key Vault extension folder.

Open Side Panel

Click the Key Vault icon in your browser toolbar. The secure side panel opens immediately.

Set Password & PIN

Create your master password and 4-digit quick-unlock PIN. Your encrypted vault is ready!

FAQ

Frequently Asked Questions

Everything you need to know about Key Vault and digital licensing.

What is Key Vault?

Key Vault is a Chrome browser extension that opens in the side panel and lets freelancers and developers keep API keys and credentials in an encrypted vault stored on their own device. Keys are organized into Personal and per-client workspaces.

How does the subscription and activation work?

The extension is free for personal use, and a monthly or yearly subscription unlocks unlimited client workspaces. After paying, the customer receives a license key by email and pastes it into the extension to activate it. No physical goods or services are involved.

Where are my API keys stored?

Keys are encrypted locally and stored on your own device using Chrome's secure storage APIs. No passwords, credentials, or keys are ever transmitted to or stored on Genstay servers.

What happens if I forget my master password?

Because Key Vault is zero-knowledge and has no central server, your keys cannot be recovered without your master password. We recommend generating an encrypted backup from Settings right after adding your keys.

Who develops and publishes Key Vault?

Key Vault is developed and published by Genstay, founded by Praveen Reddy. Support inquiries can be directed to genstay.in@gmail.com.
